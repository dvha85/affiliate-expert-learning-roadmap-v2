# Starter kit — M01 Smallest Deterministic Bot

Starter kit này **không chứa một bản implementation thứ hai**. Runtime canonical để học và test là `lab/affiliate-bot`.

## Dùng theo thứ tự

1. Học `curriculum/M01/M01.1` đến `M01.4`.
2. Chạy `lab/affiliate-bot`.
3. Dùng `CHECKPOINTS.md` để kiểm Mission gate.
4. Dùng `M01-OPERATED-EVIDENCE-TEMPLATE.md` cho learner evidence cá nhân.
5. Chạy executable eval pack tại `evals/M01-deterministic-bot/`.

## Không làm ở M01

- không LLM/Agent;
- không n8n automation;
- không publish/action;
- không approval/executor;
- không nâng weak score thành business recommendation.

```text
M01 ship = deterministic decision behavior + failure cases + operated proof
```
