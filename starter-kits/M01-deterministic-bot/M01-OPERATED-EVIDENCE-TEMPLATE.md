# M01 Operated Evidence (bằng chứng đã vận hành) — bản sao cho người học

> Copy file này vào `learner/M01/M01-OPERATED-EVIDENCE.md`. Không commit personal/account evidence (bằng chứng cá nhân/tài khoản).

## 1. Runtime (môi trường chạy)

```text
Date/time: ngày/giờ
Bot/formula version: phiên bản Bot/công thức
Commands run: các lệnh đã chạy
```

## 2. Dự đoán trước khi chạy

```text
Input/case: đầu vào/ca kiểm thử
Predicted state: trạng thái dự đoán
Predicted ranking: thứ hạng dự đoán
Why: vì sao
```

## 3. Kết quả quan sát được

```text
Observed state: trạng thái quan sát được
Observed ranking: thứ hạng quan sát được
Matched prediction? yes/no: có khớp dự đoán không? có/không
What changed in my understanding: điều gì thay đổi trong hiểu biết của tôi
```

## 4. Failure case (ca lỗi)

```text
Case ID or change: ID ca hoặc thay đổi
Invariant being tested: bất biến đang được kiểm thử
What should fail if implementation is wrong: điều gì phải fail nếu triển khai sai
Observed result: kết quả quan sát được
```

## 5. Ranh giới Reality (thực tế) từ M00

```text
Which fields are backed by real M00 evidence: trường nào được bằng chứng thật M00 hỗ trợ
Which fields are missing/unknown: trường nào còn thiếu/chưa biết
Did I fabricate any field? must be NO: tôi có bịa trường nào không? phải là KHÔNG
Decision state justified by current evidence: trạng thái quyết định được bằng chứng hiện tại biện minh
```

## 6. Explain-back (tự giải thích lại)

```text
What price × commission_rate proves: price × commission_rate chứng minh gì
What it does NOT prove: nó KHÔNG chứng minh gì
Why real evidence != RECOMMEND: vì sao bằng chứng thật != RECOMMEND
Why Decision != Approval != Execution: vì sao quyết định != phê duyệt != thực thi
```
