# Starter kits — cách dùng

Mỗi thư mục Mission cung cấp README, checkpoint và operated-evidence template tương ứng.

- M01–M02: dùng learner baseline tại `lab/affiliate-bot/`.
- M03–M11: ngoài checkpoint riêng của Mission, **bắt buộc áp dụng** `CONTINUITY-CHECKPOINT.md` để chứng minh capability mới đã được gắn vào cùng learner Bot/workspace.

`lab/mission-runtime/` chỉ là conformance oracle/harness (bộ đối chiếu chuẩn). Chạy demo/test ở đó không thay Integration Evidence, Reality evidence hay Operated evidence.

Chi tiết kiến trúc: `docs/architecture/LEARNER-BOT-CONTINUITY.md`.
