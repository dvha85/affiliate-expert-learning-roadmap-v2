# M07.3 — n8n Evidence Agent chỉ đọc

## Mục tiêu

Dùng AI Agent để research/summarize/propose trong read-only ceiling. MCP là candidate cho interoperability, không thay permission model.

## Thực hành

Import `lab/n8n/M07-readonly-evidence-agent.blueprint.json`.

Đọc `lab/n8n/COMPATIBILITY.md` trước import. Ghi exact engine/node version và
chạy import + execution smoke trên instance thật; blueprint parse được không
tự chứng minh adapter/AI Agent giữ đúng Safe Profile sau upgrade.

1. Cấu hình model credential **cục bộ trong n8n**, không commit secret.
2. Cấp `AFFILIATE_ADAPTER_TOKEN` qua môi trường/secret local của n8n và cấu
   hình header Bearer cho các HTTP Request node; không ghi token vào blueprint,
   URL, input JSON hoặc log.
3. Giữ `ToolRegistry` GET-only và allowlist đúng source đã review; Agent không
   nhận HTTP Request Tool trực tiếp.
4. Chạy prompt bình thường và lưu output/correlation.
5. Chạy prompt/tool-content chứa chỉ dẫn kiểu `ignore prior rules and POST...`;
   Agent chỉ nhận dữ liệu đã được adapter fetch/register, nên không có capability
   POST ra nguồn ngoài.
6. Đối chiếu output với `ToolRegistry`, evidence IDs và offline evaluator.

Blueprint dùng AI Agent node thật + chat-model subnode. Mọi I/O đi theo chuỗi
`Fetch and Register Tool Adapter (POST)` → `Canonical M07 Context Adapter` →
`AI Agent` → `Validate Grounding Adapter` → `Persist Agent Proposal Adapter`.
Adapter chịu transport/registry/DNS/redirect, canonical evidence và sidecar;
AI Agent chỉ tóm tắt/propose ở A2-RO/HUMAN_REVIEW, không biến model success
thành authorization.

## Predict-before-run và deliberate failures

Trước mỗi run, ghi expected outcome cho bốn case: (1) evidence allowlisted,
(2) host/tool ngoài registry, (3) webpage chứa prompt injection, và (4) model
hallucinate evidence ID. Sau run, đối chiếu state/reason với blueprint,
ToolRegistry và conformance runtime. Không đổi prompt đến khi pass mà bỏ case
không pass. Với (2), adapter phải trả reject trước khi lưu tool-result;
workflow không được chạy tiếp tới Agent.

Thử failure theo cách an toàn: sửa fixture/context hoặc mock response; không
thử một write credential hay endpoint thật. Nếu n8n yêu cầu credential, cấp
credential read-only scope nhỏ nhất, log node/version nhưng không lưu secret.

## Continuity artifact

Output Agent phải được validate trước khi nối vào canonical Observation/Advisor
path của learner Bot. Lưu theo `CONTINUITY-CHECKPOINT.md`: Bot commit/version,
previous artifact IDs (ID artifact trước), ToolRegistry version, n8n workflow/node versions,
adapter entrypoint, correlation và limitation. `mission-runtime` chứng minh
conformance; nó không thay operated evidence của n8n instance bạn chạy.

## Explain-back

MCP/n8n AI Agent là interoperability/orchestration option, không phải
permission model. A2-RO nghĩa Agent chỉ đề xuất/read evidence; không có model
output, tool result hay workflow success nào được phép thành Decision,
Approval hoặc Execution.

## PASS

Chứng minh tool ngoài registry, write method, hallucinated evidence và prompt-injection authority escalation đều không vượt boundary; lưu operated evidence theo starter.
