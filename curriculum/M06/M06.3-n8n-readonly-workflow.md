# M06.3 — watcher synthetic canonical cho n8n

## Mục tiêu

Dùng n8n cho schedule/orchestration, nhưng không dùng JavaScript workflow để
parse nguồn, phân loại claim, hash input hay tự dựng `HistoryRecord`. Các bước
đó thuộc shared M06 adapter và learner store.

## Thực hành

Khởi động adapter local rồi import
`lab/n8n/M06-readonly-watcher.blueprint.json`. Blueprint mặc định chỉ dùng
fixture synthetic `br13-offer-fixture/v1`; không thay URL thành seller/public
source và không thêm credential. Sửa fixture chỉ để thực hành các ca hợp lệ và
reject của profile này.

```bash
go run ./cmd/bot watcher serve /tmp/affiliate-runtime/history.jsonl 127.0.0.1:8787
```

Luồng phải thực sự đi qua:

```text
schedule
→ M06 Adapter Input (fixture JSON)
→ Build and Append Canonical M06 Adapter
→ shared M06 builder → M00 conversion → learner HistoryRecord
→ append → resolve/replay MATCH → ACK
→ report record_id
```

`Build and Append Canonical M06 Adapter` chỉ báo
`canonical_history_handoff=ACK` và `canonical_history_persisted=true` sau khi
adapter trả `APPENDED` hoặc `EXACT_DUPLICATE`. N8n không có watcher cache và
không sở hữu canonical history.

## Continuity Gate (cổng liên tục của learner Bot)

Record do adapter tạo phải đi vào **cùng canonical evidence/history path** mà
learner Bot dùng cho M00–M08. M07/M08 resolve record từ history đã persist, chứ
không nhận snapshot do workflow gửi kèm.

Lưu Integration Evidence theo `starter-kits/CONTINUITY-CHECKPOINT.md`, gồm Bot
version/commit, blueprint hash, adapter entrypoint, execution ID (nếu có) và
`record_id` đã resolve.

## Failure cases

- GET/URL/seller claim được tự thêm ở n8n thay vì profile adapter;
- fixture thiếu field, source URL sai, status khác 200 hoặc số bị mất precision;
- retry cùng fixture không trả `EXACT_DUPLICATE`;
- adapter lỗi nhưng workflow vẫn báo persistence;
- workflow cố dùng static data làm canonical history;
- coi fixture synthetic là real evidence hoặc business truth.

## Giới hạn

JSON blueprint và static validator không phải bằng chứng import/run trên một
n8n instance. Chỉ dùng profile synthetic này cho đến khi RP-10 có nguồn được
phép, policy transport, instance và operated evidence riêng.
