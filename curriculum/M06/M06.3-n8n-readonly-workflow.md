# M06.3 — watcher synthetic canonical cho n8n

## Mục tiêu

n8n phụ trách schedule/orchestration. Shared M06 adapter xây packet/input và ghi
learner HistoryRecord; n8n không tự hash, parse source hay sở hữu canonical history.
Blueprint dùng fixture synthetic profile br13-offer-fixture/v1; giữ URL fixture,
không tự thay thành seller/public source hoặc thêm credential nguồn.

## 1. Chạy fixture trước

Bắt đầu tại repo root. Xác minh Go/Python, Node 24 và n8n 2.38.1; chỉ rõ
JavaScript entrypoint n8n/bin/n8n cùng node executable tuyệt đối.
Các đường dẫn ví dụ dưới cần thay bằng file đã cài trên máy.

macOS/Linux:

```bash
node_path="/absolute/path/to/node"
n8n_cli="/absolute/path/to/n8n/bin/n8n"
"$node_path" --version
"$node_path" "$n8n_cli" --version
python3 scripts/run_n8n_engine_regression.py --n8n-cli "$n8n_cli" --n8n-node "$node_path"
python3 scripts/run_n8n_m06_schedule_regression.py --n8n-cli "$n8n_cli" --n8n-node "$node_path"
```

PowerShell:

```powershell
$nodePath = "C:\absolute\path\node.exe"
$n8nCli = "C:\absolute\path\n8n\bin\n8n"
& $nodePath --version
& $nodePath $n8nCli --version

python scripts/run_n8n_m06_schedule_regression.py --n8n-cli $n8nCli --n8n-node $nodePath
```

Hai runner tạo SQLite/home, token và adapter loopback riêng. M07 dùng model

kiểm Schedule Trigger thật. PASS chỉ là fixture runtime.

## 2. Lab thủ công: adapter và n8n nhận cùng token

Dùng terminal lab mới tại repo root; chọn **một** đoạn dưới. Tạo token ngẫu nhiên
**một lần trong parent shell**, khởi động adapter rồi n8n từ chính shell đó để
hai process kế thừa cùng CANONICAL_ADAPTER_TOKEN. Không tạo token khác ở terminal
thứ hai, không echo/copy vào blueprint, URL, JSON hoặc log.

Bản n8n chạy qua isolated_n8n_environment: bỏ settings DB/queue/n8n kế thừa,
dùng N8N_USER_FOLDER dưới thư mục tạm, SQLite và loopback.
N8N_BLOCK_ENV_ACCESS_IN_NODE=false chỉ nằm trong environment của child lab để
expression đọc token; không áp dụng lên instance cá nhân/production. Home này
dùng khóa mã hóa fixture, chỉ dành cho fixture/mock; provider credential thật cần
instance/quyền riêng đã review.

Port 8787 (adapter) và 5688 (n8n) phải đang trống; nếu không, dừng và chọn cấu hình
lab khác, không dừng process không thuộc bài này. Sau import mở
http://127.0.0.1:5688, giữ workflow inactive khi sửa case.

macOS/Linux (node_path/n8n_cli giữ giá trị đã kiểm ở bước 1):

```bash
(
  set -eu
  work="$(mktemp -d)"
  mkdir "$work/store"
  printf 'Lab workspace: %s\n' "$work"
  export CANONICAL_ADAPTER_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
  go -C lab/affiliate-bot build -o "$work/bot" ./cmd/bot
  "$work/bot" watcher serve "$work/store/history.jsonl" 127.0.0.1:8787 &
  adapter_pid=$!
  trap 'kill "$adapter_pid" 2>/dev/null || true' EXIT
  sleep 1
  kill -0 "$adapter_pid"
  python3 - "$work" "$node_path" "$n8n_cli" <<'PY'
import sys, subprocess
from pathlib import Path
sys.path.insert(0, "scripts")
from n8n_runtime_env import isolated_n8n_environment
from run_n8n_engine_regression import choose_port
env = isolated_n8n_environment(Path(sys.argv[1]), broker_port=choose_port(), node_path=Path(sys.argv[2]))
env.update({"N8N_BLOCK_ENV_ACCESS_IN_NODE": "false", "N8N_LISTEN_ADDRESS": "127.0.0.1", "N8N_HOST": "127.0.0.1", "N8N_PORT": "5688", "N8N_SECURE_COOKIE": "false"})
raise SystemExit(subprocess.call([sys.argv[2], sys.argv[3], "start"], env=env))
PY
)
```

PowerShell (nodePath/n8nCli giữ giá trị từ bước 1):

```powershell
$work = Join-Path ([IO.Path]::GetTempPath()) ("affiliate-n8n-lab-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path (Join-Path $work "store") | Out-Null
Write-Output ("Lab workspace: " + $work)
$bytes = New-Object byte[] 32
$rng = [Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
$rng.Dispose()
$env:CANONICAL_ADAPTER_TOKEN = [Convert]::ToBase64String($bytes)
$bot = Join-Path $work "bot.exe"
$history = Join-Path $work "store/history.jsonl"
go -C lab/affiliate-bot build -o $bot ./cmd/bot
if ($LASTEXITCODE -ne 0) { throw "Bot build failed" }
$adapter = Start-Process -FilePath $bot -ArgumentList @("watcher", "serve", ('"' + $history + '"'), "127.0.0.1:8787") -WindowStyle Hidden -PassThru
try {
    Start-Sleep -Seconds 1
    if ($adapter.HasExited) { throw "Adapter failed to start; check port/path" }
@'
import sys, subprocess
from pathlib import Path
sys.path.insert(0, "scripts")
from n8n_runtime_env import isolated_n8n_environment
from run_n8n_engine_regression import choose_port
env = isolated_n8n_environment(Path(sys.argv[1]), broker_port=choose_port(), node_path=Path(sys.argv[2]))
env.update({"N8N_BLOCK_ENV_ACCESS_IN_NODE": "false", "N8N_LISTEN_ADDRESS": "127.0.0.1", "N8N_HOST": "127.0.0.1", "N8N_PORT": "5688", "N8N_SECURE_COOKIE": "false"})
raise SystemExit(subprocess.call([sys.argv[2], sys.argv[3], "start"], env=env))
'@ | python - $work $nodePath $n8nCli
} finally {
    if (-not $adapter.HasExited) { Stop-Process -Id $adapter.Id }
    Remove-Item Env:CANONICAL_ADAPTER_TOKEN -ErrorAction SilentlyContinue
}
```

Dừng n8n bằng Ctrl+C rồi kiểm tra hai process lab đã dừng. Ghi lại đường work
được in ở đầu, giữ history để đọc lại/replay. Khi restart, bỏ bước mktemp/New-Item
và gán work về **đúng đường cũ**; tạo một token phiên mới duy nhất rồi cho cả hai
process kế thừa. Token phiên có thể đổi khi cả hai đã dừng, dữ liệu history thì
phải giữ nguyên. Manual editor/topology chưa được suy PASS từ regression CLI.

## 3. Bài tập persistence và bài so sánh nội dung

Import [blueprint M06](../../lab/n8n/M06-readonly-watcher.blueprint.json) vào lab.
M06 Adapter Input chứa fixture_json. Mỗi ca dưới cần một execution capture;
tắt schedule lúc đổi fixture để tránh phát sinh tick không kiểm soát.

| Case | Thao tác trên bản copy fixture | Expected persistence | Kiểm history |
|---|---|---|---|
| first_import | fixture gốc, history lab trống | `APPENDED` | 1 record; record_id; ACK=true, persisted=true |
| exact_retry | giữ nguyên toàn bộ event | `EXACT_DUPLICATE` | cùng ID; count/hash không đổi |
| identity_conflict | đổi price trong body, giữ correlation_id và observed_at | `HANDOFF_ERROR` | reject; history bytes không đổi; không tới Report |
| new_event | đổi price, correlation_id=event-2 và observed_at=2026-09-04T00:00:00Z | `APPENDED` | 2 records; giữ record cũ |
| restart_retry | restart adapter/n8n, dùng cùng history và event-2 | `EXACT_DUPLICATE` | cùng record_id; replay MATCH |
| unavailable_adapter | dừng adapter lab rồi chạy workflow | reject trước ACK/report | history không đổi |

Sai/thiếu Bearer, URL ngoài profile, JSON lỗi hoặc status khác 200 phải bị
từ chối trước persistence. Ghi HTTP/node error và hash trước/sau; không log token.
POST tới /v1/m06/fixture-import là ghi nội bộ loopback có auth, không cấp quyền
POST ra nguồn ngoài.

Change detection là bài **riêng**, chạy từ repo root:
go -C core test ./m06 -count=1 và python scripts/validate_n8n_m06_cases.py
(macOS dùng python3). Core normalizer so sánh fingerprint với previous_hash:
không có hash trước → NEW; hash giống → UNCHANGED; hash khác → CHANGED.
Chỉ đổi thứ tự key của cùng JSON vẫn giữ fingerprint. Ghi context/hash thực sự
đã dùng; không lấy report persistence của blueprint làm kết quả change detection.

```text
change detection: NEW | UNCHANGED | CHANGED
persistence: APPENDED | EXACT_DUPLICATE | HANDOFF_ERROR
```

Luồng blueprint phải là:
```text
M06 Adapter Input → Build and Append Canonical M06 Adapter
→ Require Canonical Store ACK → Report Canonical M06 Result.
```
ACK chỉ được nhận khi status APPENDED/EXACT_DUPLICATE, canonical_history_ack=true,
canonical_history_persisted=true và record_id không rỗng. Output Report là kết quả
persistence, canonical_history_handoff=ACK; Observation nằm trong record canonical
được resolve từ history.

## 4. Troubleshooting và bàn giao

| Triệu chứng | Kiểm gì | Kết quả cần giữ |
|---|---|---|
| 401/403 | Bearer thiếu/sai; hai process có kế thừa cùng token không | reject trước mutation; không in token |
| connection refused/timeout | adapter đúng port 8787, còn chạy không | không có ACK/report giả |
| env access denied | child n8n lab có N8N_BLOCK_ENV_ACCESS_IN_NODE=false không | không sửa config global |
| không tìm thấy go.mod/file | cwd repo root, node/CLI path và parent history tồn tại | sửa path, không reset history |
| model failure ở M07 | model stub/credential/version riêng, không phải adapter token | lưu failure, không coi là grounding PASS |

Dùng [template M06](../../starter-kits/M06-readonly-watcher/M06-OPERATED-EVIDENCE-TEMPLATE.md)
và [Continuity Checkpoint](../../starter-kits/CONTINUITY-CHECKPOINT.md):
ghi rõ Bot commit, blueprint hash, engine/Node version, history path/count/hash,
execution ID, record_id, ACK/persisted, replay, auth/rejection và limitation.
Fixture chỉ là capability/integration evidence. Nguồn selected/public và
operated deployment cần profile, quyền và evidence riêng.
