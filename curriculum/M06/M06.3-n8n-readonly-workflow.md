# M06.3 — n8n workflow chỉ đọc

## Mục tiêu

Dùng n8n cho schedule/orchestration khi Mission cần automation; deterministic validation vẫn là boundary riêng.

## Thực hành

Import `lab/n8n/M06-readonly-watcher.blueprint.json`, thay `subject_id` và URL bằng nguồn public được phép rồi kiểm tra URL/ToS trước khi activate schedule. Không thêm credential có write scope.

Workflow phải thực sự đi qua:

```text
schedule
→ allowed source
→ GET
→ canonical Observation
→ NEW / UNCHANGED / CHANGED
→ append local canonical history
→ report correlation/source
```

Chạy thủ công tối thiểu hai lần trước khi bật schedule. Lần thứ hai với cùng nội dung phải ra `UNCHANGED`; khi nội dung đổi phải ra `CHANGED`.

## Failure cases

- POST/PUT/PATCH/DELETE hoặc host ngoài allowlist;
- output n8n không map về canonical Observation;
- retry tạo observation mơ hồ hoặc mất correlation;
- coi content hash/change state là business truth.

## PASS

Bạn chạy workflow với nguồn thật read-only, lưu operated evidence theo starter và giải thích được `NEW/UNCHANGED/CHANGED`, provenance, limitation và authority ceiling.
