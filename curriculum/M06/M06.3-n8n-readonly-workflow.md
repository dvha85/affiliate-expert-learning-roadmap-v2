# M06.3 — n8n workflow chỉ đọc

## Mục tiêu

Dùng n8n cho schedule/orchestration khi Mission cần automation; deterministic validation và canonical business state vẫn là boundary riêng.

## Thực hành

Import `lab/n8n/M06-readonly-watcher.blueprint.json`, thay `subject_id` và URL bằng nguồn public được phép rồi kiểm tra URL/ToS trước khi activate schedule. Không thêm credential có write scope.

Workflow phải thực sự đi qua:

```text
schedule
→ allowed source
→ GET
→ canonical Observation có observation_id
→ watcher cache chỉ để NEW / UNCHANGED / CHANGED
→ canonical-history handoff sang Deterministic Core
→ report correlation/source
```

## Watcher cache (bộ nhớ đệm) != canonical history (lịch sử chuẩn)

Blueprint có thể dùng `$getWorkflowStaticData` để nhớ fingerprint phục vụ change detection (phát hiện thay đổi). State này chỉ là **watcher cache (bộ nhớ đệm của watcher)**:

```text
n8n watcher cache
!= append-only HistoryRecord
!= replay history
!= canonical audit/business state
```

Mất watcher cache có thể làm lần chạy sau trở lại `NEW`; nó **không được** làm mất/reset canonical HistoryRecord. Node `Append Canonical History` trong blueprint hiện chỉ đánh dấu handoff contract (hợp đồng bàn giao) sang Deterministic Core; nó không `store.history.push(...)` trong n8n static data.

Chạy thủ công tối thiểu hai lần trước khi bật schedule. Lần thứ hai với cùng nội dung phải ra `UNCHANGED`; khi nội dung đổi phải ra `CHANGED`. Kiểm tra output có `observation_id`, `subject_id`, `source_url`, `observed_at`, `correlation_id` và `canonical_history_handoff=REQUIRED`.

## Continuity Gate (cổng liên tục của learner Bot)

Observation do watcher tạo phải đi vào **cùng canonical evidence/history path** mà learner Bot đã xây từ M00–M02. Không tạo một kho history riêng chỉ vì n8n dễ lưu static data.

Lưu Integration Evidence theo `starter-kits/CONTINUITY-CHECKPOINT.md`, gồm Bot version/commit, previous artifact refs, adapter entrypoint và state ownership.

## Failure cases (các ca lỗi)

- POST/PUT/PATCH/DELETE hoặc host ngoài allowlist;
- output n8n không map về canonical Observation có `observation_id`;
- dùng n8n static data làm canonical history;
- retry tạo observation mơ hồ hoặc mất correlation;
- adapter tạo ontology/history riêng không nối M02;
- coi content hash/change state là business truth.

## PASS

Bạn chạy workflow với nguồn thật read-only, lưu operated + integration evidence và giải thích được `NEW/UNCHANGED/CHANGED`, provenance, limitation, cache-vs-canonical-state và authority ceiling.
