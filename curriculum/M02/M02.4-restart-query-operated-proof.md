# M02.4 — Restart proof, historical query và operated evidence

## Mục tiêu

Chứng minh history/replay sống qua process restart và learner thực sự vận hành nó.

## Capability flow

```text
record t1
→ append history
→ stop process
→ record t2 hoặc load history
→ restart
→ query sorted by as_of
→ replay all records
→ rerun same history + same version
→ same report
```

Một in-memory slice PASS test nhưng mất hết sau restart **không đạt M02 Operated**.

## Reality flow

Sau khi M01 PASS, learner dùng ít nhất một `product_id` thật từ M00/M01:

```text
E1 observation t1
→ HistoryRecord t1

E1 observation t2
→ HistoryRecord t2
```

`t1` và `t2` phải có `observed_at` khác nhau. Nếu value không đổi, `UNCHANGED` vẫn hợp lệ; M02 kiểm history semantics chứ không ép market phải thay đổi.

## Freshness không dùng clock ẩn

M02 chưa cần scheduler. Nếu report cần freshness, phải truyền rõ:

```text
observed_at + explicit as_of + max_age policy
```

Không rải `time.Now()` trong deterministic replay, vì cùng history chạy ở hai ngày khác nhau sẽ cho report khác mà không đổi input contract.

## Operated evidence

Dùng template:

`starter-kits/M02-history-replay/M02-OPERATED-EVIDENCE-TEMPLATE.md`

và lưu bản cá nhân dưới `learner/M02/`.

Ghi tối thiểu:

- t1/t2 identity + timestamps;
- overwrite failure mental/actual attempt;
- append result;
- duplicate + conflict result;
- out-of-order query result;
- restart proof;
- replay report;
- deterministic rerun;
- limitation + next measurement.

## Mission PASS

M02 PASS chỉ khi:

```text
Capability + Reality + Operated
```

CI xanh hoặc synthetic eval pack PASS không tự tạo E1 Reality PASS.
